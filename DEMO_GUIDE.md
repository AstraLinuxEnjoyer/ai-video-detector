# TRACE: демонстрация дипломного проекта

## На этом компьютере

Запустите `start-demo.cmd` двойным кликом или выполните из папки проекта:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\start-demo.ps1
```

Адрес по умолчанию: `http://127.0.0.1:8787`. Если порт занят, выбирается следующий.
Окно запуска должно оставаться открытым. `Ctrl+C` останавливает сервер.
По умолчанию используется CPU: запуск не мешает обучению занимать видеопамять.
На текущем компьютере можно явно выбрать CUDA:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\start-demo.ps1 -Device cuda
```

## Что показываем руководителю

1. Загрузите MP4/MOV/MKV/AVI/WebM/M4V: не более 400 МБ и 120 секунд.
2. Этапы и прогресс отражают действительную обработку: чтение видео,
   извлечение кадров, оценки первой модели, клипы второй, карты влияния.
3. На дорожке каждый кадр открывает соответствующий момент в плеере.
   График показывает реальные, отдельно рассчитанные оценки моделей.
4. «Подробный отчёт» показывает исходные кадры рядом с Grad-CAM, оптическим
   потоком или частотным графиком. Модель и отсчёт можно выбрать.
5. Четыре кадра с наибольшей оценкой первой модели получают Grad-CAM.
   Для остальных карта отсутствует; интерфейс сообщает об этом.
6. Порог фиксирован на сервере. HTML включает текст, графики и кадры,
   открывается без сервера и печатается. JSON хранит основания и параметры
   решения, CSV содержит оценки кадров. Подробнее: [TRACE_ENSEMBLE.md](TRACE_ENSEMBLE.md).

После перезапуска сервера последний завершенный анализ доступен через кнопку
истории. Незавершенная задача не возобновляется: видео нужно загрузить снова.
Одновременно обрабатывается один ролик. Отмена останавливает обработку после
текущего вычисления/чтения; кнопка новой загрузки включится после остановки.

## Какие модели подключены

- EfficientNet V2-S: лучшие веса `hybrid_v2`, общий кадр и пять локальных
  участков; усреднение 50/50 соответствует обучению.
- R(2+1)D-18: лучшие веса `motion_flow_v1`, 9 кадров с частотой 4 FPS,
  8 полей остаточного движения после вычитания медианного смещения.
  Нормализация и параметры оптического потока соответствуют обучению.
- Спектральная ветка `spectral-face-v3`: три кадра яркости и область лица
  при наличии. Даёт 10% общего балла, не поднимает тревогу сама. Если ветка
  недоступна, работают две остальные. Демо не переобучает модели.

Фиксированные веса берутся из `demo_weights/manifest.json`, а при отсутствии
экспорта — из соответствующих обучающих папок `cache`. Экспорт записывает
контрольные суммы и номера эпох. После нового обучения экспорт не обновляется
сам: остановите демо и выполните `export-demo.ps1`, затем снова запустите сайт.
Экспорт выберет актуальные лучшие веса. Уже запущенный сервер держит старые
веса в памяти до перезапуска.

## Ограничения, которые нужно сказать честно

Это исследовательская демонстрация, не экспертная система и не валидированный
детектор любых локальных правок. Оценка 0.99 не означает 99% вероятности фейка.
Кадры берутся примерно раз в 2 секунды, клипы движения перекрываются с шагом
1.5 секунды. Временная подсветка приблизительная: короткое вмешательство может
быть пропущено. Модели не обучены выдавать точные пространственные маски правок.

Grad-CAM показывает влияние на fake-логит полного кадра: это не доказательство
генерации, не сегментация и не гарантия причинной интерпретации. Усреднение
структуры/движения/спектра 63/27/10 — эвристика, не обученный метаклассификатор.
Для уведомления о возможном вмешательстве нужны высокие оценки кадра и
движения на одном участке. Повтор высоких оценок только одной ветки
выделяет отрезок для ручной проверки без положительного вердикта. Одиночный
пик даёт неопределённость, но не интервал. Отсутствие сигналов не подтверждает
подлинность. Числовые пороги ещё не прошли независимую валидацию.

При FPS ниже 4 либо длительности меньше 2.25 с модель движения воздерживается:
интерфейс сообщает, что движение не оценено. Ошибочные клипы отмечаются
как отсутствующие оценки; другие видео вместо них не подставляются.
HDR приводится к SDR для декодирования/плеера. Плеер получает отдельную
H.264-копию без звука; модели анализируют оригинал, а не пережатый плеер.

## Перенос на другой Windows-компьютер

Архив с ансамблем: `releases/TRACE-ensemble-windows.zip` (команда сборки в
[TRACE_ENSEMBLE.md](TRACE_ENSEMBLE.md)). В нём код, веса и FFmpeg;
нет датасетов, пользовательских видео, отчетов, среды разработки или чекпоинтов.

1. Перенесите архив и распакуйте его в обычную папку, например `D:\TRACE-demo`.
2. Установите Python 3.12 (64-bit) с https://www.python.org/downloads/windows/.
   При установке включите Python Launcher / PATH.
3. Запустите `setup-demo.cmd`. Первый запуск требует интернет для загрузки
   зависимостей (~несколько ГБ места для среды), видеокарта не обязательна.
4. Запустите `start-demo.cmd`. Сайт открывается в браузере на localhost.
   После установки работа сайта и анализ не требуют интернета.

Установщик не скачивает датасеты и не отправляет видео в сеть. Поддерживается
Windows x64. Это переносной комплект с установкой зависимостей, не полностью
автономный EXE. Проверка установки на отдельном чистом компьютере пока нужна.
Архив можно пересобрать через `export-demo.ps1`.

## Логи и хранение

`demo_runtime/demo.log` — действия моделей, ошибки, оценки и итог.
`demo_runtime/<id>/` — оригинал, копия плеера, кадры, поток, карты и отчеты.
Видео не удаляются автоматически: при остановленном сервере можно удалить
папки ненужных анализов внутри `demo_runtime`. Сам сервер доступен только через
loopback; размещение в интернете/LAN потребует отдельной защиты.

Git хранит исходный код, но не большие веса, датасеты и пользовательские
видеоматериалы. Для переноса готовой демонстрации нужен ZIP, не только git clone.
