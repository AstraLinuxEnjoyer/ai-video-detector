# TRACE interface

## Direction
User-requested cybersecurity and video-forensics theme. Quiet graphite working surface, Manrope, lime actions, honest diagnostic language. One media specimen is the signature visual. No fake scores, terminal commands or decorative metric panels.

## Primary surface
A clear task-based layout takes priority over ornamental motifs. Top navigation, a concise introduction and one upload workspace. Result replaces the upload composition with video and a readable conclusion. The detailed report expands below the workspace on request. Model information and exports use native HTML dialogs; optional explanation uses native details. Surface strategy is recorded in the surface brief.

## Typography
Self-hosted variable Manrope with Cyrillic. Desktop display 68px, mobile 34–42px, result headings 24–25px. Functional labels 11–14px. Tabular numerals for time and scores. No technical monospace styling except checksum values.

## Color
Background #101314, workspace #191d1e, foreground #f0f3ed, secondary #a5afaa, accent #ccf68b. Blue #aabcf1 distinguishes motion data in the detailed report. Peach #f5a993 signals suspicion or errors. All content stays on one dark visual system.

## Motion
The media specimen responds across the whole upload area: pointer spotlight, scan reticle, 3D parallax and a periodic scan. Its quiet idle layers pause offscreen and in hidden tabs. Button feedback uses 160–200ms transforms and a single hover sheen. Supplementary explanation enters over 650ms; task controls are immediately present.

Native disclosures animate measured height and body opacity/translation in both directions. Small disclosures take 280ms; the tall analysis report takes 420ms. Rapid clicks reverse from the current state. Native dialogs enter in 280ms and exit in 220ms, while Escape is immediate. Tabs have a sliding indicator; evidence images crossfade in 250ms. The shared strong ease-out is cubic-bezier(.23,1,.32,1).

Lenis 1.3.27 smooths wheel input and anchor navigation using native page coordinates; touch remains native. Sticky navigation, the location indicator and a thin scroll-position bar preserve orientation. Expanding and collapsing the report coordinates page height with scrolling.

The footer motion button explicitly toggles the complete motion layer. It defaults to the OS reduced-motion preference and stores an explicit choice in localStorage. Reduced mode removes spatial movement and scroll smoothing. Fine-pointer effects never run on touch. Keyboard disclosures and Escape are immediate. Native details, dialogs, focus management and controls remain the semantic foundation.

## Responsive behavior
Desktop upload uses an asymmetric media-object/copy layout. Result uses media beside conclusion. On tablet and mobile the video and result stack. The detailed view becomes one column. Navigation hides only the supplementary anchors, keeping upload, history and status available.
