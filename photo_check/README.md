# Проверка фотографий

Клади фотографии прямо в эту папку. Подпапки real/fake не нужны: программа не использует имена папок как правильные ответы. Можно положить одну или несколько фотографий, вложенные папки тоже просматриваются.

Из PowerShell в корне проекта:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\check-photos.ps1
```

Результаты выводятся в консоль: REAL (модель считает настоящим) или FAKE (модель считает сгенерированным), имя файла и fake_score. Оценка около 0.5 дополнительно помечается NEAR THRESHOLD. fake_score не является гарантированной вероятностью, а ответ модели может быть ошибочным.

Поддерживаются JPG, JPEG, PNG, WEBP, BMP, TIF, TIFF. HEIC/HEIF и RAW сначала экспортируй в JPG/PNG. Учитывается EXIF-поворот; прозрачность накладывается на белый фон. Анимации и многостраничные изображения отклоняются. Исходники не изменяются.

Используется best.pt последнего spatial_v2-запуска, номер эпохи выводится перед результатами. Порог для фото равен 0.5. Порог из video-validation намеренно не переносится автоматически на одиночную фотографию. Размер ограничивается 640 по длинной стороне, затем используются центральный crop и нормализация validation. Фотография не проверяет движение или весь ролик и может существенно отличаться от обучающих видеокадров.

По умолчанию расчёт идёт на CPU. Команда не запускает обучение и не меняет checkpoint. Каждый запуск проверяет все фотографии в папке заново; для теста только новой фотографии перенеси старые из папки.

Результаты дополнительно сохраняются в reports/photo_check_<дата_время>.json с номером эпохи и SHA-256 весов. Фотографии этой папки игнорируются Git и не включаются в обучение.

Другую папку или один файл можно передать так:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\check-photos.ps1 --input "C:\path\to\photo.jpg"
```
